# AI-Generated Image Detection

A research pipeline for binary classification of AI-generated vs. real images using convolutional neural networks, with a focus on cross-dataset generalisation.

The core research question is whether CNN-based detectors learn genuine generative artefacts that transfer across datasets and generator families, or whether they overfit to dataset-specific shortcuts. To answer this, models are trained on one dataset and evaluated against all others, producing a generalisation matrix for each architecture.

---

## Datasets

| ID | Name | Source | Images | Task |
|----|------|--------|--------|------|
| `ai_vs_human` | AI vs Human Generated Dataset | [Kaggle](https://www.kaggle.com/datasets/alessandrasala79/ai-vs-human-generated-dataset) | ~60k | Binary (real / AI) |
| `dataset_b` | Defactify Image Dataset | [HuggingFace](https://huggingface.co/datasets/Rajarshi-Roy-research/Defactify_Image_Dataset) | 96k | Binary (real / AI) |

`ai_vs_human` contains images generated by Stable Diffusion, MidJourney, and DALL-E paired with real photos from Pexels, Unsplash, and WikiArt. `dataset_b` is caption-aligned (MS-COCO captions), with each real image paired with five synthetic versions generated by SD 2.1, SDXL, SD 3, DALL-E 3, and MidJourney v6.

## Setup

### Prerequisites

- Google account with sufficient Drive space (~130 GB for both datasets processed)
- Google Colab (CPU or T4 GPU runtime)
- Kaggle account + API token (`~/.kaggle/kaggle.json`)
- HuggingFace account + access token

### Install dependencies

```bash
pip install -r requirements.txt
```

On Colab, `torch` and `torchvision` are pre-installed. You only need:

```bash
pip install -q datasets huggingface-hub kagglehub seaborn
```

## How to run

All commands are run from the project root (`licenta/`). On Colab, prefix with `!` or use a `%%bash` cell. Every script mounts Google Drive automatically on first run.

### 1. Download and prepare datasets

**Dataset A — Kaggle**

```bash
# Download to Drive (run once)
python scripts/download_dataset_a.py

# Split 80/10/10, resize to 224×224, save to Drive
python scripts/prepare_dataset_a.py
```

Requires `~/.kaggle/kaggle.json` or the env vars `KAGGLE_USERNAME` and `KAGGLE_KEY` to be set.

**Dataset B — HuggingFace**

```bash
# Download from HuggingFace, resize to 224×224, save directly to Drive
python scripts/download_dataset_b.py

# Verify counts and write manifest.csv
python scripts/prepare_dataset_b.py
```

Set your HuggingFace token in `scripts/download_dataset_b.py` or via the `HF_TOKEN` environment variable. Both scripts are resumable — already-saved images are skipped, so interrupted runs can be restarted safely.

---

### 2. Train

```bash
# ResNet50 on dataset A
python -m src.training.train_resnet50 --dataset ai_vs_human

# ResNet50 on dataset B
python -m src.training.train_resnet50 --dataset dataset_b

# ResNet18 on dataset A
python -m src.training.train_resnet18 --dataset ai_vs_human

# ResNet18 on dataset B
python -m src.training.train_resnet18 --dataset dataset_b
```

Optional flags:

| Flag | Default | Description |
|------|---------|-------------|
| `--epochs N` | 5 | Number of training epochs |
| `--batch_size N` | 64 | Batch size |
| `--not_resized` | off | Pass if images are NOT pre-resized to 224 on disk |

A checkpoint is saved after every epoch to `checkpoints/<dataset>/<model>/`. The best validation accuracy is tracked and printed at the end of training.

---

### 3. Evaluate a single model

```bash
python -m src.evaluation.evaluate_resnet50 --dataset ai_vs_human
python -m src.evaluation.evaluate_resnet18 --dataset dataset_b
```

The script automatically finds the checkpoint with the highest validation accuracy in the corresponding checkpoint directory. Outputs (metrics CSV + confusion matrix PNG) are saved to `logs/<dataset>/<model>/`.

---

### 4. Cross-dataset generalisation matrix

```bash
python -m src.evaluation.cross_dataset_matrix --model resnet50
python -m src.evaluation.cross_dataset_matrix --model resnet18
```

This script iterates every `(trained_on × tested_on)` combination across all datasets defined in `config.py`. For each cell it loads the best checkpoint for that training dataset and evaluates it on the test split of the target dataset. Missing checkpoints or datasets are skipped gracefully and shown as N/A in the output.

Outputs are saved to `logs/cross_dataset_matrix/<model>/`:

- `resnet50_accuracy_matrix.csv` and `.png`
- `resnet50_f1_matrix.csv` and `.png`
- `resnet50_precision_matrix.csv` and `.png`
- `resnet50_recall_matrix.csv` and `.png`

## Configuration

All paths and hyperparameters are centralised in `src/config.py`. The most likely things to change:

```python
DRIVE_ROOT  = "/content/drive/MyDrive/licenta"  # change if your Drive path differs
BATCH_SIZE  = 64
EPOCHS      = 5
```

To add a third dataset, uncomment and fill in the `dataset_c` entry in `DATASETS` — everything else (training, evaluation, matrix) picks it up automatically.
